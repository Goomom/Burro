Hieraquia, Expressôes e Layout

Hieraquia no DOM

Hieraquia no DOM ( Documento Object Model) é a estrutura
em forma de árvore que organiza todos os elementos de uma
página HTML.

Cada elemento pode ter:

  • Pai ( parent )
  • Filho ( children )
  • Irmãos ( siblings )

Expressôes regulares

Igualdade ( = )

input [type='text']

Busca o input que tenha o type = 'text'.

input [type='number']

Busca o input que tenha o type = 'number'.

Começa com ( ^= )

a[href ^= "https"]

Pega o link ( a ) que inicie com o texto especificado.

<- Esse será escolhido

Termina com ( $= )

img[src $= '.png']

Seleciona a imagem cujo src termine com .png

<- Esse será escolhido

Contém ( *= )

div[class *= 'card']

Pega a div cuja classe tenha a palavra card em qualquer posição.

Ambos serão selecionados

Contém palavra ( ~= )

div[class ~= 'active']

Busca div cuja classe tenha a palavra active separada por espaços.

<- Esse será escolhido

Começa com prefixo + hífen ( |= )

p[lang |= 'en']

Busca o prefixo determinado adicionando um hífen nele. pt-
